# Annual Accounts presentation

Generated authenticated transport presents Accounts-owned workspace and readiness
facts and routes overrides, reviews, acknowledgements, permissions, manual test
evidence and TT02 imports. Readiness is a preview of supplied source facts and
cannot authorize a durable filing. The capability owns all calculations and
state decisions. The UI preserves complete recorded metadata without treating
unknown metadata as successful authority acceptance. Requests are uncached and
bounded by a timeout. Audit remains the existing post-write action continuation.
